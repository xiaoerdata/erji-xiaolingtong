# 自有数据与指标口径

## 用户文件

CSV/JSON 至少明确对象标识、日期、数值、单位、频率、币种与复权口径。不要根据文件名猜净值类型或收益率单位。重复的“对象+日期”需要查明，不能随意保留一行；缺失为 NULL，不自动补零或插值。

随包 `assets/example-nav.csv` 是刻意简化的**合成数据**，不是实际产品或业绩。可用来验证本地计算链路：

```sh
python3 scripts/compare_nav.py assets/example-nav.csv --value-kind adjusted-nav --output comparison.json
```

从技能目录运行。脚本只用 Python 标准库，不联网、不安装依赖、不执行交易。CSV 列为 `product,date,nav`，净值必须为有效正值。同一文件混合单位净值、复权净值或币种时先拆开并确认口径。

## 脚本的比较含义

- 使用**所有对象共同存在的观测日期**，日期排序后各自以首点归一；缺失日期不前向填充。不满足至少两个共同观测点则报错。
- 区间收益 = 末值 / 首值 − 1。
- 年化收益 = (末值 / 首值)^(365.25 / 日历天数) − 1。区间不足一年时返回 NULL，不放大短样本表现。
- 采样最大回撤 = min(当期净值 / 截至当期的峰值 − 1)。这是共同日期样本上的回撤，可能漏掉完整日频内更深回撤。
- 不输出夏普或年化波动率：不规则估值、缺失观察和频率差异需要另行确认，不能拿一个默认年化系数硬算。
- `--value-kind reference-nav` 用于 近似参考净值，输出明确标记近似口径。不能把它改名为原始净值。

## 其他常用指标

需要夏普时，先确定共同区间、收益频率、总回报口径、无风险利率及其年化转换、标准差估计方式；波动为零或样本不足返回不可计算。排名给出有效样本数、排除原因与同分处理。不同频率直接年化后的夏普不能未经说明直接排队。

负数回撤的“更小”易歧义：用“绝对回撤更浅/更深”描述。服务端指标与自行重算不同，先核对区间、频率、分红与复权，不按更好看的数值挑选。
